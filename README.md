# Соночка Study 💗

Персональное Windows-приложение для Соны: учебные долги, календарь, предметы, фокус и быстрый доступ к сервисам Мининского университета.

## Автообновления

Приложение использует публичный канал этого репозитория:

- `stable.json` — текущая стабильная версия;
- `SonochkaStudy-latest.zip` — пакет обновления;
- GitHub Actions автоматически пересобирает пакет после изменения приложения.

Пользовательские данные Соны хранятся только локально на компьютере и в GitHub не отправляются.
