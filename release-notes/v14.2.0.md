Соночка Study 14.2.0

• Исправлено чтение обложек Windows: преобразование в PNG, повтор после временного сбоя, синхронизация обычного и полноэкранного плеера.
• Общий прогресс учитывает домашку, долги, события и остальные сохранённые задачи. Есть отдельные фильтры домашки, долгов и событий.
• Кнопка воспроизведения выровнена. Улучшена читаемость фокуса на личном фоне; свои фото и обои Windows доступны в настройках.
• Календарь стал немного компактнее.
• Новый спокойный трёхсекундный звук запуска.
• При запуске доступное обновление показывается со списком изменений и выбором «Обновить сейчас» / «Позже».
• Удалена очистка неизвестных задач и старых оценок при загрузке. Резервная копия включает настройки и личный фон.

Как обновить: в установленной программе открой Настройки → Скачать копию, затем Проверить обновления → Установить. После установки закрой старое окно и открой SonochkaStudy.exe из прежней папки. Не переноси папку приложения и используй тот же браузер: сохранения привязаны к адресу приложения и профилю браузера.

Для новой установки скачай portable ZIP, полностью распакуй его и запусти SonochkaStudy.exe. Включи песню в настольной Яндекс Музыке. Личный фон: Настройки → Фон режима фокуса.

Проверено на тестовой копии: домашка, сохранение после перезапуска, перенос данных 14.1.3 → 14.2.0, прогресс, управление плеером, обложки через Windows API, уведомление об обновлении. Компьютер Соны отдельно не проверялся; текущая тестовая система не имеет активной сессии Яндекс Музыки.
