# Соночка Study 14.1.0

Готовый пакет обновления подготовлен и протестирован локально.

## Изменения
- Обложки Яндекс Музыки: Windows media-session thumbnail + резервная обложка из метаданных Яндекс Музыки.
- Одна обложка и состояние play/pause в обычном и полноэкранном «Фокусе».
- Исправлено центрирование иконки play/pause.
- Фон «Фокуса»: текущие обои Windows / собственная фотография / без изображения.
- Спокойный короткий звук запуска.
- Общий прогресс: домашка + долги + события календаря, с отдельными вкладками по категориям.
- События календаря можно отмечать выполненными.
- Календарь стал компактнее.
- Безопаснее обновлятор: SHA-256, резервный снимок, остановка старого медиамоста, откат при ошибке копирования.
