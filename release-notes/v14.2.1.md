Соночка Study 14.2.1 — Яндекс Браузер и обложки

• Запуск явно находит Яндекс Браузер и передаёт ему режим отдельного окна приложения. Убран запасной запуск HTML через обычную браузерную вкладку.
• Все внешние HTTP/HTTPS-ссылки интерфейса открываются в Яндекс Браузере независимо от системного браузера по умолчанию.
• Путь к HTML и профиль Яндекса остаются прежними; отдельный пустой профиль не создаётся.
• Обложки PNG, JPEG, GIF и WebP передаются из Windows напрямую. Для других форматов сохранено преобразование в PNG.
• Резервное изображение Яндекс Музыки скачивается медиамостом и передаётся в интерфейс внутри ответа. Расширена проверка результатов поиска без подмены исполнителя.
• Устранено перекрытие периодических опросов плеера. Повторный показ уже загруженной обложки восстанавливает её видимость.
• «Скопировать диагностику» теперь включает версию медиамоста, источник обложки, ошибку получения и размер декодированного изображения.

Обновление: сначала Настройки → Скачать копию, затем Проверить обновления → Установить. Закрой старое окно и открой SonochkaStudy.exe из прежней папки. Не запускай отдельный HTML. Все файлы архива должны лежать рядом с EXE, включая BrowserSupport.ps1.

Проверено: параметры запуска Яндекса и маршрутизация ссылок с тестовым обработчиком запуска; сохранения, управление плеером и отображение изображений в отдельном профиле Edge; чтение Windows-обложки; реальная загрузка изображения Яндекс Музыки. Яндекс Браузер и активная сессия Яндекс Музыки на компьютере Соны напрямую не проверялись. Если обложка всё ещё отсутствует, пришли текст Настройки → Скопировать диагностику.
